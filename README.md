# Systemile installers

Official Windows installer downloads for Gym, Hotel, Library, Shop and Jewellery Systemile. Application source, signing keys and customer data are not stored here.

Choose your software and Windows edition at [Systemile Downloads](https://systemile-site.vercel.app/download). Installers are stored in [GitHub Releases](https://github.com/Dipak1533/systemile-installers/releases), rather than Git history.

Four separate feeds are maintained per software: Windows 10/11 x64, Windows 10 x86, Windows 7 SP1 x64 and Windows 7 SP1 x86. Windows 11 uses the modern x64 installer. Keep the same architecture when updating an existing installation.

Existing installations without an updater need the first updater-enabled installer once. Subsequent releases appear through the software's update button. Download first, then choose Install & restart. The app saves the latest work and retains a verified local safety backup before installation; ordinary closing does not install updates. Network failure does not interrupt offline business operation.

Releases are opt-in. Save and a verified local safety backup precede installation. Windows 7 and Windows 10 compatibility remains unverified on actual systems. Windows publisher certificate signing is not yet configured.

Do not upload project archives or credentials. Release assets are immutable and signed update metadata is validated by installed apps.
